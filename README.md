# homebrew-tap

Homebrew tap for [AutoDev](https://github.com/HEETMEHTA18/autodev) — The App Store for Developers.

## Install

```bash
brew install HEETMEHTA18/tap/autodev
```

Or tap first, then install:

```bash
brew tap HEETMEHTA18/tap
brew install autodev
```

## What is AutoDev?

AutoDev is an open-source, cross-platform developer environment bootstrapper. It scans your project and installs all missing languages, frameworks, databases, and DevOps tools with a single command.

```
autodev setup      — scan & install missing tools
autodev doctor     — check environment health
autodev audit      — scan dependencies for vulnerabilities
autodev github     — analyze a GitHub profile
```

Docs: https://github.com/HEETMEHTA18/autodev
